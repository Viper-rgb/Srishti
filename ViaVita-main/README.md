# ViaVita

ViaVita is a mobile‑first, employee‑first workplace platform designed to simplify communication, collaboration, and everyday work experiences. Built with **Flutter** and **Dart**, it provides a seamless, high‑performance cross‑platform experience on Android and iOS.

## Features

- **Employee‑Centric Workplace Hub** – Intuitive interface tailored to everyday employee workflows.
- **Real‑Time Collaboration** – Streamlined communication modules for modern distributed teams.
- **Dynamic Data Synchronization** – Robust REST API integration for instantaneous system updates.
- **Predictive State Management** – Utilizes **Provider** for a reactive, efficient user experience.
- **Responsive Material UI** – Custom, scalable widget architecture following Material Design guidelines.

## Tech Stack

- **Framework**: Flutter (cross‑platform Android & iOS)
- **Language**: Dart
- **State Management**: Provider
- **Networking**: HTTP package (REST API & JSON parsing)
- **Architecture & Design**: Clean Code principles, Material Design guidelines

## Prerequisites & Setup

1. **Flutter SDK** – Ensure the Flutter SDK is installed and configured on your machine.
2. **Clone the Repository**
   ```bash
   git clone https://github.com/vinayaksuresh/viavita.git
   cd viavita
   ```
3. **Install Dependencies**
   ```bash
   flutter pub get
   ```
4. **Run the Application** – Launch an emulator or connect a physical device, then run:
   ```bash
   flutter run
   ```

## Coding Practices

- **Clean Code Principles** – Follows Effective Dart guidelines for clean syntax and formatting.
- **Widget Componentization** – Complex layouts are segmented into reusable widgets for optimal rendering.
- **Performance Optimization** – Uses `ListView.builder` and caching controls to ensure smooth UI responsiveness.
